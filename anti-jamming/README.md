# 北斗 B1I 抗干扰仿真

在把抗干扰算法搬上 FPGA/MCU 之前，先在 PC 上把"信号 → 干扰 → 抗干扰 → 捕获"这条链路跑通，用数字判断算法是否有效。

## 链路

```
B1I 中频生成 ──> 叠加干扰 ──> 抗干扰处理 ──> 并行码相位搜索 ──> 捕获度量对比
 (2.046 Mcps)    (CW/宽带/脉冲)  (陷波/频域/消隐)     (FFT 相关)
```

## 两个实现

| 实现 | 位置 | 状态 |
| --- | --- | --- |
| **C 参考实现** | `src/full_chain_check.c` | ✅ 已在本地编译运行，结果见下 |
| **MATLAB 全链路** | `matlab/run_full_chain.m` | ⚠️ 脚本已实现，尚未在 MATLAB 环境运行 |
| MATLAB 双端比对 | `matlab/verify_c_output.m` | ⚠️ 同上 |

**为什么先用 C 复现**：没有 MATLAB 授权时，用 C 把同样的公式跑一遍，确认"算法方向对不对"；
等有环境再把 MATLAB 版跑一遍，两边结果互相印证。这就是"双实现互验"。

## 实测结果（C 版）

```
$ make && ./demo
N=20460 spc=10 Ps=0.500 A_jam=31.62 |w|=31.833
before: 8.68 dB @ 61423
after : 31.47 dB @ 0
gain  : +22.79 dB
```

三个结论：

1. **陷波收敛**：|w| = 31.8，正好等于干扰幅度 31.62，2 万点内收敛；
2. **捕获度量改善 +22.79 dB**，峰值 SNR 从 8.68 提到 31.47；
3. **干扰存在时相关峰不在 0**，跑到 61423 —— 这就是"干扰淹没信号"的量化表现；
   抗干扰后峰回到真实码相位 0。

## 构建与运行

```bash
make
./demo
```

需要 GCC（C11）和 `-lm`。

## 关键参数

| 参数 | 值 | 说明 |
| --- | --- | --- |
| Fs | 20.46 MHz | 每码片 10 个采样点 |
| IF | 4.098 MHz | 中频 |
| JSR | 30 dB | 干信比 |
| mu | 0.01 | LMS 步长 |
| 码 | 11 级 m 序列，2046 码片 | B1I 风格 |

## 已知限制

- MATLAB 版尚未实机运行，README 中的数字仅来自 C 版；
- 无噪声场景（未加 AWGN），结果偏乐观；
- 单星、单径，未做多径与多星联合捕获；
- 频域抑制未保护信号带，实际工程需加保护带。
